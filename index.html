Privacy Policy

Last Updated: August 2026

This Privacy Policy explains how the Dragon/NoiTu Discord Bot ("the Bot") collects, processes, and uses information while providing its services.

Information We Collect

The Bot may process the following information:

  • Discord User IDs
  • Discord Server IDs
  • Discord Channel IDs
  • Message content submitted during gameplay

How We Use Information

The collected information is used only to operate the game, including:

  • Validating Vietnamese word-chain rules.
  • Checking player submissions.
  • Preventing duplicate words.
  • Managing active game sessions.
  • Sending game responses.

Message content is processed only for gameplay purposes and is never used for advertising, analytics, or profiling.

Data Storage

The Bot does not permanently store users' message content unless temporarily required to maintain the current game session.

Artificial Intelligence

User messages are never used to train artificial intelligence or machine learning models.

Data Sharing

We do not sell, rent, or share user information with any third party.

User Choice

Users may stop interacting with the Bot at any time by leaving the game, removing the Bot from their server, or simply not sending game messages.

Contact

If you have any questions regarding this Privacy Policy, please contact the developer through Discord.
